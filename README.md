🍕 Pizza Sales Dashboard | Power BI
An interactive Pizza Sales Analysis Dashboard built using Microsoft Power BI to analyze sales performance, customer ordering patterns, pizza categories, pizza sizes, and best/worst-selling products.The dashboard transforms pizza sales data into meaningful business insights through interactive KPIs, charts, filters, and product-level analysis.

📊 Dashboard Preview
🏠 Home Dashboard
The Home page provides an overall view of pizza sales performance, including revenue, orders, pizza quantity sold, average order value, daily trends, monthly trends, category performance, and pizza size analysis.

🏆 Best/Worst Seller Dashboard
The Best/Worst Seller page provides detailed product-level analysis using Top 5 and Bottom 5 pizzas based on:
>Revenue
>Quantity Sold
>Total Orders

🎯 Project Objectives
The main objectives of this project are to:
Analyze overall pizza sales performance.
Identify the busiest days and months.
Analyze sales by pizza category.
Analyze sales by pizza size.
Identify the best-selling pizzas.
Identify the worst-selling pizzas.
Compare pizza performance using revenue, quantity, and orders.
Create an interactive business intelligence dashboard.

📈 Dashboard Features
1. Sales Overview
The dashboard provides a high-level overview of the business using KPI cards for:
Total Revenue
Average Order Value
Total Pizza Sold
Total Orders
Average Pizza Per Order

2. Daily Order Analysis
A daily trend chart is used to compare total orders from Sunday to Saturday.
The dashboard highlights that:
Friday has the highest number of orders.
Weekend and Friday/Saturday periods show strong ordering activity.

3. Monthly Order Analysis
The monthly trend visual analyzes order volume throughout the year.
According to the dashboard:
July has the highest number of orders.
January is also among the strongest months.
October records the lowest number of orders in the displayed period.

4. Pizza Category Analysis
The dashboard analyzes sales contribution across different pizza categories:
Classic
Supreme
Chicken
Veggie
The category visuals compare the percentage contribution of each category to overall sales.

5. Pizza Size Analysis
Pizza sales are also analyzed by size:
Large
Medium
Regular
X-Large
XX-Large
The dashboard shows that Large pizzas contribute the highest share of sales.

🏆 Best & Worst Sellers
The second dashboard page focuses on product performance.

🥇 Top 5 Pizzas
Top-performing pizzas are identified based on:
Revenue
Quantity Sold
Total Orders
This helps identify the products that generate the strongest business performance.

📉 Bottom 5 Pizzas
The dashboard also identifies the lowest-performing pizzas based on:
Revenue
Quantity Sold
Total Orders
This analysis can help businesses investigate underperforming products and make better menu decisions.

💡 Key Business Insights

Based on the dashboard:
📅 Ordering Pattern
Friday has the highest daily order volume, indicating strong customer demand toward the end of the working week.

📆 Monthly Performance
July records the highest monthly order volume, while October shows comparatively lower demand.

🍕 Category Performance
The Classic pizza category contributes the highest share among the displayed pizza categories.

📏 Size Performance
Large pizzas contribute the largest share of sales by pizza size.

🏆 Product Performance
The Best/Worst Seller page makes it easy to identify products that generate high revenue and orders as well as products that may require further analysis.
